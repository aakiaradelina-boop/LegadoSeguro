
# Requerimientos funcionales y no funcionales - LegadoSeguro

Esta carpeta contiene la documentación de los requerimientos funcionales y no funcionales del sistema LegadoSeguro.

## Requerimientos funcionales

Describen las funciones que permitirá realizar el sistema, como el registro e inicio de sesión, la gestión del legado digital, la administración de beneficiarios y la verificación y notificación.

## Requerimientos no funcionales

Describen las condiciones de calidad del sistema, como la seguridad, la privacidad, el rendimiento, la disponibilidad y la facilidad de uso.
