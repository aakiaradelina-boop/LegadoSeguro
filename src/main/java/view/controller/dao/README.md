
# DAO - LegadoSeguro

Esta carpeta contiene las clases encargadas del acceso y la gestión de datos del sistema LegadoSeguro mediante SQL Server.

## Clases DAO principales

- UsuarioDAO.java
- LegadoDigitalDAO.java
- BeneficiarioDAO.java
- VerificacionDAO.java
- NotificacionDAO.java
- AdministradorDAO.java

## Funciones

- Registrar y consultar usuarios.
- Gestionar los legados digitales.
- Registrar y consultar beneficiarios.
- Gestionar las verificaciones.
- Administrar las notificaciones.
